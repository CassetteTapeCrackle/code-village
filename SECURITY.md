# Security

If you find a security problem in Code Village, please report it privately. Do not open a public
issue for it.

Open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer
sees the report.

Please include:

- what the problem is, and where (the game in the browser, the board, the teacher, or the
  agent connection)
- the steps to reproduce it
- what someone could do with it

You will get an answer as soon as possible. Please give a fix time to ship before you talk about
the problem in public.
